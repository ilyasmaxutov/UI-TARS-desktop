# Реализованные сценарные переходы
Это каталог поведения существующих экранов, не новый список обещаний. Вызовы моделей здесь сценарные. Подсчёт импортированных метрик — реальный.

| Ситуация | Где попробовать | Правило взаимодействия |
|---|---|---|
| Первое поручение | «12 сценариев» → первое поручение | Оригинал рядом с рабочим EN-текстом; отправка отделена от сохранения |
| Исполнитель работает | работа идёт → нижнее поле | Уточнение адресовано текущему ходу, исходная цель не затёрта |
| Ход завершился до steer | «Ход уже завершился» → уточнить | Уточнение остаётся; явное продолжение, не скрытый дубль |
| Потерян ACK | «Ответ на отправку потерян» | Сверка прежней команды, число отправок не растёт |
| Новая цель | «Цель изменилась» | Старое заключение не даёт принять новый результат |
| Внешняя правка | «Файл изменён вручную» | Три версии → новое предложение → ещё одна проверка |
| Ложное завершение | «Ложное готово» | Кнопка принятия закрыта, замечание указывает незакрытое требование |
| Отмена | «Отмена не подтверждена» | Запрос и факт остановки различаются; новая попытка не включается |
| Квота | «Лимит подключения» | Нет автоматических вызовов; продолжение не обходит ожидание |
| Новый исполнитель | «Замена исполнителя» | Сначала остановка и адресное разрешение передачи |
| Два окна | «Две редакции промпта» | Старый текст сохраняется отдельно; ни один не затирается |
| Нет подключения | «Нет исполнителя» | Черновик/экспорт/наблюдение доступны; отправка объяснимо заблокирована |

Дополнительные коллизии: несохранённый редактор сохраняется при смене вкладки; сообщение к файлу не переадресуется роли при переходе на другой экран; переключение сценария сохраняет предыдущий черновик; вторая карточка проверки на другом листе не создаёт второго исполнителя; модельные данные и импортированная телеметрия имеют разные обозначения.

## Приёмка поведения интерфейса человеком
Самостоятельно, без Computer Use: открыть HTML на Windows, пройти полный путь и конфликт, проверить масштабы 100/150/200%, узкое окно, длинные русские строки, клавиатуру и возврат фокуса. Кнопка «Принять» не должна выглядеть как публикация. Импорт настоящего журнала должен удалить маркировку сценарных метрик, но не создать видимость живого агента. Статические проверки разметки этого не доказывают.

Непокрыто: несколько окон ОС с живой IndexedDB/файловым доступом; полноценное произвольное редактирование исполняемых связей; история многих настоящих проектов; работа подключённых агентов; материализация результата на диск. Эти ограничения прямо показаны, не закрыты имитацией.
