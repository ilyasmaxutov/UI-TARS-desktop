## Что проверяют 65 тестов

Границы вывода на элемент/пакет, исходные статусы и refs, точное число байтов, replay старого снимка, новый ID при изменении источника, duplicate-local cache, зависимости и отказ отдельной ветви, неизвестный исход check без повторного исполнения, реальные stdin/stdout MCP, ограниченный диапазон бинарных данных, ошибка длинной строки и byte-inspect, generated/secret exclusions, выход за корень/ссылка, манифест и повреждение материала, реальный процесс с exit7, неполный захват при лимите, отмена, фиксированный Git, выбор npm-native exe без исполнения shim.

Gate проверяется отдельным получателем: слишком большой/неизвестный вход; учёт инструкций и function schemas; неизвестная история; metadata не обходит dedup; канонический JSON; auth не журналируется; редирект/429 не повторяются; сетевой обрыв; частичный SSE; restart in-flight; неизменность task policy; сохранение ответа; отказ дискового резерва до отправки; race при одном слоте; неизвестный encrypted input закрыт. Это не исполнение настоящей модели.

## Внедрение в Studio

`native/crates/host/src/codex/economy.rs` подключает этот же EXE, а не отдельную модель/LLM-сервис. Путь — sibling host или явный `STUDIO_ECONOMY_EXE`. Добавлены две Rust-проверки, **38 Rust-тестов всего остаются написанными, не исполненными**. В capabilities намеренно `modelInputHardLimit=false`, `providerRetriesEnforced=false`, `pending-target-codex`. Сырой stderr вместо discard сохраняется локально с пределом1МиБ и метаданными полноты; универсального удаления секретов нет.

## Что НЕ подтверждено

1. Выполнение Windows EXE, PowerShell-скриптов, NTFS/ACL/junction-конкуренции. EXE unsigned.
2. Rust/Tauri, текущие Cargo pins и полный UI→host→Codex. Go helper не делает эту ветку автоматически готовой.
3. Реальное принятие всех config keys установленным Codex, эффективность selection на реальной задаче, охват чужих hooks/MCP.
4. Жёсткий предел каждого модельного входа **всего Codex**, денежный/подписочный потолок, процент экономии, безошибочное сохранение смысла отбора.
5. Прозрачная совместимость экспериментального gate с ChatGPT subscription/opaque reasoning/WebSocket. Gate выключен по умолчанию и не назначает чужой endpoint.
6. Принудительная OS-изоляция программы из check-списка. Pathguard/child process — не sandbox. Общий объём хранилища — ограничение приложения, не квота ОС.
7. Универсальный журнал всех действий ОС и lossless recovery streaming-событий провайдера.

Нет обращения к пользовательскому CODEX_HOME/credentials. Нет GUI, браузера, dev-server, Computer Use, скачивания моделей, внешних модельных запросов и оплачиваемых тестов. Пакет не меняет глобальную конфигурацию Codex. G1/G2/G3 и полный E01 остаются незакрытыми; приняты отдельные локальные механизмы, не универсальный «strict».

## Воспроизведение для разработчика

```powershell
npm run verify
cd native/tools/economy
$env:GOPROXY='off'; $env:GOTOOLCHAIN='local'
go test -race -count=1 -v ./...
go vet ./...
```

Для `-race` требуется поддерживаемая host-toolchain/C-компилятор. Пользователю EXE они не нужны. Доступный нативный selftest — без компилятора и модели. Исходники внешних библиотек не загружались: Go stdlib уже был на стенде.

Параметры конечных EXE: `-buildvcs=false -trimpath -ldflags="-s -w"`, CGO=0. Связь с исходниками фиксируется в SOURCE_REVISION.json архива и Git bundle, а не во встроенной метке dirty checkout. После пересборки с этими параметрами Linux selftest повторён; binary hashes — в binaries.json.
