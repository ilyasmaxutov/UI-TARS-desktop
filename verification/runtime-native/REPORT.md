## Исправленные причины отказов

Первая целевая сборка выявила 17 ошибок: `rusqlite 0.41.1` не принимает `u64` непосредственно в качестве SQL INTEGER. Добавлена проверяемая граница `u64 ↔ i64`: значения вне диапазона отклоняются до записи, отрицательные значения из хранилища не превращаются в unsigned. Публичные контракты и проверки переполнения сохранены.

Вторая причина — преобразование LF в CRLF при Windows checkout. Оно меняло байты десяти диагностических образцов, тогда как планы содержат хеши исходных байтов. `.gitattributes` закрепляет LF и бинарные файлы. Проверка целостности не ослаблена, тестовые ожидания не переписаны.

## Что эта сборка ещё не проверяет

Интерфейс приложения не запускался, реальный Codex и модели не вызывались. Сквозная сессия на пользовательском Windows 11, работа системного трея/сна, IPC fault injection, изоляционные G1/G2/G3 и измерение производительности остаются отдельными требованиями. Самопроверка хоста не выдается за тест GUI/IPC.

Комплект без цифровой подписи. Для его запуска не нужны Rust, Go или Node. Все три EXE должны лежать рядом; интерфейс использует системный WebView2.
