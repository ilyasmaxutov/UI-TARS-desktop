## Ошибки, найденные и исправленные

Пустой поиск на пустом дереве давал ложное отрицательное основание. Восстановленный read_matches доверял изменённому data.json прежнего search-артефакта того же размера. Оба случая сначала воспроизведены (`regressions-before-fix.log`), затем закрыты кодом и тестами. Также исправлены неполнота при изменении файла без совпадений, порядок unknown/partial, сверка сводки с запечатанным отчётом. Также обнаружена гонка учёта диска с атомарным переименованием временного .pending-файла: измерение целиком повторяется не более четырёх раз только для исчезнувшего временного файла. Ошибки чтения постоянного артефакта, прав и квоты не игнорируются. Три отдельные регрессии и пять повторных race-прогонов диагностик прошли. Слишком большие обязательные вопросы/идентификаторы отчёта теперь отклоняются ещё до чтений, а не после исчерпания выходного лимита. При смене версии завершённые 0.4 пакеты доступны как старый снимок, незавершённые не исполняются новым кодом автоматически.

Промежуточный Go-прогон выявил несовместимость новой проверки version с прежними неполными journal fixtures. Исправлен код совместимости: пустое version допустимо только при совпадающем fingerprint текущей версии. Старые тесты не изменены. Промежуточный лог сохранён, финальный прогон чистый.

## Native source / границы

Написаны **44 Rust-тестов**, из них 6 новых исследовательских, **ни один здесь не запускался**. Rust/Tauri не компилировались, Cargo.lock не создан. Windows helper EXE и test EXE cross-compiled, но Windows execution/NTFS/ACL/junction races не проверены; EXE unsigned. Нет готового нового полного Studio EXE/MSI.

TaskStore и host импортируют запечатанный отчёт по task/revision в одну существующую БД, без нового inference loop. MCP completion → TaskStore и живой GUI ещё требуют целевого прогона. Структурированные Finding проверяются TS и показываются при импорте; автоматический semantic-evaluator/capture свободных выводов агента не принят.

Счётчик отсутствия прогресса не считает переименование/новый session новым свидетельством. Native admission source учитывает общий TaskStore. Standalone MCP не имеет авторитета над внутренним циклом Codex: поля бюджета и skill не гарантируют запрета его постороннего shell или всех модельных вызовов. W3 не объявлен полностью принят.

Исследовательский scope — проверка пути и фиксированные чтения, не ОС-изоляция. Хэширование источников ограничено и может быть partial; до/после — не атомарный snapshot. Неизвестный исход сохраняется, автоматической мутации/retry нет. Сохранились ограничения 0.4 по полной токеновой/финансовой границе.

Нет GUI/browser/dev-server/Computer Use, paid/model calls, доступа к CODEX_HOME или credentials, смены глобальных настроек, push в GitHub.
