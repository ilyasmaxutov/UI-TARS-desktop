Diagnosis-first procedure (not another agent or model call).
For a simple range read or an already-known cause, use local_batch directly. Do not invent hypotheses to satisfy ceremony.
For an unknown failure: retain the original goal and restrictions; state 2–5 competing causal explanations, their different predicted observations, the smallest useful scope, and stopping rules. Prefer one read-only diagnostic_sweep over serial pwd/list/search/read model turns. Order cheap distinguishing checks first. Independent reads run together; dependent reads use existing search/read_matches references.
A sweep gathers observations, NOT a verdict. Compare predictions once after it returns. Check a plausible alternative and contradictory evidence before proposing a repair. Incomplete search is not absence; exit code 0 is not correctness. Hashes identify bytes, not truth. Cite evidence IDs, source versions and coverage. If the cause is established, deliver the authorized fix and a discriminating verification; do not keep planning.
If the same evidence or error repeats, change the test or stop. New session, renamed hypothesis or child must not reset the task limit. Do not poll models while waiting. Preserve unknown external effects; never send a new command ID just to retry one. A bounded local result is not a request to rerun the command: inspect its saved artifact.
On interruption retain originalGoal, planVersion, evidence refs, negative results, open questions and the next executable check. New knowledge is a scoped candidate, not a permanent law. The policy is an instruction; enforcement outside these local tools depends on the installed Codex profile. This grants no permissions.
