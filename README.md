## Что открыть

- `dist/assistant.html` — экран реальных задач/сессий для нативной оболочки. В обычном браузере операции хоста недоступны, работает локальный импорт журнала JSONL. Сценарного переключения агента здесь нет.
- `dist/index.html` — прежний канвас и встроенные локальные преобразования; не изменяет оригинал.
- `dist/assistant-scenarios.html` — отдельно обозначенный сценарный Desk. Его кнопки не управляют Codex.

Закрытие браузерной страницы прекращает её локальную работу. Фоновая работа native host — отдельный непроверенный пока путь.

## Что изменилось

Mounted-проект хранит ссылку на папку, а не всё содержимое в JSON. Задача, редакция цели, сессия Codex и графовый запуск разделены. Старый текстовый профиль и его лимиты сохранены.

В Rust-хост добавлен stdio-клиент App Server: рукопожатие, создание/возобновление треда, отправка/уточнение/прерывание хода, сохранение ограниченного потока событий и read-only сверка. Tauri предоставляет только перечисленные операции. Нативный Direct-профиль пока read-only; это не принятая OS-изоляция. Внешний вызов требует явного подключения и пользовательского действия. Установленная версия Codex и пользовательские hooks/MCP требуют отдельной проверки.

Для неидемпотентных команд сохраняется send-fence до отправки. После потери ACK повтор не выполняется автоматически. Отдельный отменяющий tombstone позволяет снять только неотправленное поручение. Результат модели не принимается по статусу completed. Смысловой руководитель и файловая приёмка ещё не подключены.

## Проверка доступного кода без GUI

```powershell
npm install --ignore-scripts
npm run verify
node tools/check-codex-integration.mjs .\new-integration-evidence
```

Последняя команда запускает **тестовый** дочерний JSON-RPC процесс, обрывает его после записи запроса до ACK, открывает локальную SQLite заново и сверяет историю. Она не вызывает Codex, модель, сеть или GUI. Папка результата должна отсутствовать.

Файловые встроенные сценарии 0.2 сохранены:

```powershell
node tools/local-run.mjs --input .\fixtures\example --output .\new-proposal --template normalize
```

Node нужен для разработки/CLI-проверок, не как обязательный runtime целевого Rust-приложения. Python/Java/PHP не добавлены.

## Нативная проверка на Windows

Для сборки исходников нужны закреплённый Rust, MSVC build tools, Node и Go. Для запуска готового EXE эти компиляторы не нужны; интерфейс Tauri использует WebView2. `native/Cargo.lock` совпадает с файлом успешно выполненной Windows-сборки.

```powershell
.\scripts\Build-Windows.ps1 -ResolveDependencies
.\scripts\Verify-Native.ps1 -Offline
```

Первый вызов выполняет CLI-тесты и сборку по существующему lockfile. Флаг разрешения зависимостей нужен только при отсутствии lockfile. Он не запускает GUI/браузер/dev-server. Эта сборка реально выполнена в Windows CI. Второй скрипт проверяет подготовленную локальную среду. Рабочую базу следует резервировать перед испытанием миграции v4. Возврат к старому host с новой базой блокируется версией схемы.

## Пути реализации

| Путь | Назначение |
|---|---|
| `src/core/` | Прежние встроенные операции; `WorkspaceBinding` дополнен без замены старого `Project` |
| `src/assistant/` | Контракты задачи, внешний outbox, применимость review, host-backed интерфейс |
| `assistant/src/telemetry.js` | Сохранённый исходный анализатор Desk |
| `assistant/src/live-events.js` | Преобразование наблюдаемых App Server событий |
| `native/crates/core/src/task_store.rs` и `schema/v3.sql` | Задачи, сессии, intent/ACK/unknown, события и миграция |
| `native/crates/host/src/codex/` | Rust-транспорт: компилируется в Windows; живой сеанс ещё не испытан |
| `tools/integration-lab/` | Только тестовый получатель/Node facade; не второй production runtime |
| `verification/integration-0.3/` | Воспроизводимые результаты и границы доказательства |

## Не объявлено готовым

Живой Windows→Tauri→host→Codex, нативный журнал и power-loss, все схемы Codex, безопасная публикация в оригинал, семантический перевод и надзор, автоматический G0-08 по закрытым обязательствам, строгий финансовый потолок, полный OTEL/command log, исследовательские ветки, полная изолированная площадка. Наличие source-кода и фикстур не заменяет эти проверки. Все 96 исходных PF остаются в матрице; G1/G2/G3 не закрыты.
